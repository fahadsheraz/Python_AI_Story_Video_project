# Colab Workers

These files are starter notebooks/scripts for Google Colab.

## Module 4 Starter

Use:

```text
character_generation_starter.py
```

In Colab:

1. Open a new Colab notebook.
2. Copy sections from `character_generation_starter.py`.
3. Set `JOB_ID` to your current job, for example:

```python
JOB_ID = "job_0011"
```

4. Run all cells.

Expected output in Google Drive:

```text
My Drive/
  AI_Story_Video_Project/
    jobs/
      job_0011/
        output/
          characters/
            character_prompts.json
        status.json
```
